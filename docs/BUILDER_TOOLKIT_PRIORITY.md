# Veyra Builder — expanded tool priorities

Research checkpoints (October 2026):
- Wix Studio official features: responsive AI, arbitrary breakpoints, Figma integration, reusable apps, structured SEO and an integrated IDE: https://www.wix.com/studio/features
- Webflow Builder Keynote: components in CMS, side-by-side breakpoint canvas, visual AI components, component slot constraints, and localized content: https://webflow.com/blog/2026-builder-keynote
- Webflow updates: faster designer workflows, interaction management and CMS retrieval: https://origin.webflow.com/updates
These are inspiration and capability benchmarks, not evidence Veyra has implemented them.

## Must-build core tools (launch essentials)
- Sites / page manager, structured page tree, section/block palette, drag/reorder/duplicate, property inspector.
- Design system: tokens, palettes, type presets, CSS constraints, spacing, grid/flex, color contrast checker.
- Device previews, per-breakpoint controls, intelligent responsive defaults.
- Asset manager: folders, compression, responsive variants, alt text, crop/focal point, duplicate detection, quotas.
- Forms: validation, anti-spam, consent logging, notifications, submissions, CSV export.
- CMS: collections, field schemas, references, public list pages, filtering, stable pagination.
- SEO: page titles/descriptions, canonical URLs, social cards, sitemap, robots, redirects, structured data.
- Safety: autosave, draft/publish separation, versioned rollback, staging preview, broken-link checker, backup/export.
- Onboarding: site-goal-specific presets, skippable walkthrough, quick launch checklist, contextual help.
- Observability: usable performance summary, form conversion analytics, error diagnostics.

## Differentiators
- Multi-site freelancer workspace, client review links, threaded comments, approval and secure ownership handover.
- Paid AI Architect: verified entitlement, structured plan, human approval, bounded generation of allowed blocks, revision diffs.
- Paid custom domains: DNS guidance, verified ownership, automatic HTTPS with provider reconciliation, free address fallback.
- Veyra Discover: opt-in public directory, verified real work, fair exposure for new sites, searchable categories, lead conversion.
- Local commerce: Nigeria-relevant contact and delivery journeys, modular payments when thoroughly verified.
- Content health assistant: accessible copy and SEO suggestions with grounded evidence; no fabricated business facts.

## Beyond launch
- Animation timeline with scroll and state triggers, interaction presets, reduced-motion variants, performance warnings.
- Reusable components and marketplace with publishing and moderation pipeline.
- Site-wide multilingual content/SEO, translation review, accessible locale switcher.
- Experiments (A/B), conversion funnels and consent-aware analytics.
- Team roles, review environments, professional developer mode and safe code component sandboxing.
- Specialized plugins for stores, booking, events and healthcare informational content.

## Release contracts
Every surface should pass keyboard navigation, focus management, screen-reader names, error handling, responsive constraints, draft isolation, tenant isolation, provider outage behavior, and performance gates.
Never imply that an unconnected form, checkout, CMS query, domain or API is operational.
Feature access must be server-enforced and tested across separate tenant accounts.
Keep previews and public delivery distinct, log version and actor on publication.
